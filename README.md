# Student Performance Predictor

A machine learning web app that predicts a student's **final exam marks (out of 100)** from:

- Study hours per day
- Attendance percentage
- Sleep hours per night
- Previous exam marks

Built with **Python, scikit-learn and Streamlit**. The website works on **mobile, tablet and desktop**.

## Results

Three models were compared with 5-fold cross-validation; the best one was then tested once on 200 students it had never seen.

| Model | CV RMSE | Accuracy (±5 marks) | MAE | RMSE | R² |
|---|---|---|---|---|---|
| **Linear Regression (selected)** | **4.49** | **70.5%** | **3.72** | **4.59** | **0.818** |
| Random Forest | 4.67 | 68.0% | 4.09 | 5.15 | 0.772 |
| Decision Tree | 5.71 | 60.5% | 4.96 | 6.34 | 0.654 |

- **Accuracy (±5 marks)** = share of students whose predicted mark is within 5 marks of the real mark. (Plain accuracy is for yes/no classification, so it is defined this way for marks.)
- Feature engineering lowered Linear Regression's cross-validated RMSE from 5.11 to 4.49 (about 12%).
- Most important factors: previous marks, then study hours, then sleep.

## How to run it

**1. Install Python** (3.10 or newer) from python.org if you don't have it.

**2. Open a terminal in this folder** and install the packages:
```bash
pip install -r requirements.txt
```

**3. Start the website:**
```bash
streamlit run app.py
```
Your browser opens the app at `http://localhost:8501`. The trained model is already included, so it works straight away.

**4. Open it on your phone (same Wi-Fi):** the terminal also shows a **Network URL** such as `http://192.168.1.5:8501`. Type that address into your phone's browser while the laptop is running the app and both are on the same Wi-Fi network.

**5. Optional — put it online for anyone:** upload this folder to a GitHub repository, then deploy it free on Streamlit Community Cloud (share.streamlit.io), choosing `app.py` as the main file. Check Streamlit's documentation for the current steps.

## Retrain the model (optional)

```bash
python data/generate_data.py   # recreate the practice dataset (same data every time, seed 42)
python train.py                # clean, train, compare, save the best model (~40 seconds)
```

**Use real data instead:** download *StudentPerformanceFactors.csv* (the "Student Performance Factors" dataset on Kaggle), put it in the `data` folder, and run `python train.py`. The program detects it and uses it automatically. Check the Kaggle page for the units of its columns, since they may differ from the practice data.

## About the data (please read)

The dataset is **synthetic**: 1,000 students generated by `data/generate_data.py` from written-down rules, plus random noise and deliberate errors for the cleaning step. This lets every step be checked and explained, but the numbers describe those rules, not real students. Say this in your report and viva. The project report explains it in full.
